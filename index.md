## 2. Какие данные обрабатываются

В процессе работы сервиса могут обрабатываться следующие данные:

**Данные Instagram:**
- идентификатор подключённого Instagram-аккаунта;
- идентификаторы публикаций и комментариев;
- текст комментариев;
- технические сведения о событиях, передаваемых Instagram API;
- дополнительные сведения о комментариях, предоставляемые API и необходимые для работы сервиса.

**Данные Telegram:**
- Telegram ID пользователей, которым предоставлен доступ к боту;
- сообщения и команды, отправляемые боту;
- сведения, необходимые для разграничения доступа администратора и клиента.

**Данные сервиса:**
- настройки подключённого аккаунта;
- ключевые слова и параметры модерации;
- сформированные ответы на комментарии;
- технические записи о работе сервиса, ошибках и обработанных событиях.

## 3. Цели обработки данных

Информация обрабатывается исключительно для обеспечения работы AxDev Instagram Manager, в том числе для:

- получения комментариев через Instagram API;
- фильтрации и модерации комментариев;
- определения необходимости автоматического ответа;
- подготовки ответов с использованием DeepSeek API;
- отправки уведомлений и результатов обработки через Telegram;
- хранения настроек и обеспечения корректной работы сервиса;
- диагностики технических ошибок и защиты от несанкционированного доступа.

## 4. Использование сторонних сервисов

Для функционирования AxDev Instagram Manager используются следующие платформы:

**Meta / Instagram API** — получение событий и комментариев подключённого Instagram-аккаунта.

**Telegram** — взаимодействие пользователей с ботом и получение уведомлений.

**DeepSeek API** — обработка текста комментариев и подготовка ответов с использованием искусственного интеллекта. Для этого стороннему API передаётся необходимый текст комментария и контекст запроса.

**Render** — размещение серверной части приложения и хранение базы данных SQLite.

Указанные платформы могут обрабатывать информацию в соответствии со своими условиями использования и политиками конфиденциальности.

## 5. Хранение и защита данных

Для хранения данных сервиса используется база данных SQLite, размещённая на серверной инфраструктуре Render.

Доступ к информации ограничивается в соответствии с ролями пользователей и настройками сервиса.

Владелец сервиса принимает технические и организационные меры для защиты информации от несанкционированного доступа, изменения, раскрытия или уничтожения.

Данные хранятся только в течение периода, необходимого для предоставления функциональности сервиса и выполнения связанных с ним обязательств. После прекращения необходимости обработки данные удаляются или обезличиваются, если их дальнейшее хранение не требуется по закону.

## 6. Передача данных третьим лицам

Персональные данные не продаются третьим лицам.

Передача информации допускается только в объёме, необходимом для работы перечисленных в настоящей Политике платформ, предоставления функциональности сервиса, обеспечения безопасности или выполнения требований законодательства.

**[указать действующий e-mail]**

В запросе рекомендуется указать Telegram ID или сведения об Instagram-аккаунте, необходимые для поиска соответствующих данных.

Запрос рассматривается после проверки того, что он поступил от соответствующего пользователя или уполномоченного представителя.

Удаление выполняется без неоправданной задержки, если сохранение соответствующих сведений не требуется законодательством или другими законными основаниями.

Не отправляйте в запросе пароли, токены доступа или секретные ключи.
